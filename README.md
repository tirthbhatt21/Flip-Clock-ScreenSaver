# FlipClockScreensaver

### A Minimalist Flip Clock Screensaver for Windows

Bring a classic split-flap clock experience to your Windows desktop, inspired by the minimalist aesthetic of Fliqlo.

**Version:** 1.0.0  
**Platform:** Windows 10 / Windows 11 (64-bit)

---

## ✨ Features

- Classic split-flap inspired clock animation
- 12-hour and 24-hour clock formats
- Live seconds display
- AM/PM indicator
- Current date display
- Adjustable clock size and brightness
- Customizable animation speed
- Multi-monitor support
- Minimalist black background with white digits
- Lightweight, self-contained Windows application

## 📥 Download

Download the latest release:

**FlipClockScreensaver-v1.0.0-Windows-x64.zip**

Extract the downloaded ZIP file to any folder on your computer.

## 🚀 Installation

1. Download and extract the ZIP package.
2. Open the extracted folder.
3. Right-click `Install-Screensaver.ps1`.
4. Select **Run with PowerShell**.
5. Choose option `1` – Install Screensaver.
6. Windows Screen Saver Settings will open.
7. Select **FlipClockScreensaver** from the screensaver list.
8. Set your preferred waiting time.
9. Click **Apply**, then **OK**.

That's it! Your Flip Clock Screensaver is installed.

## ⚙️ Configuration

To configure your screensaver:

1. Open Windows Settings.
2. Navigate to Personalization → Lock screen.
3. Open Screen saver settings.
4. Select FlipClockScreensaver.
5. Adjust the available screensaver settings.

Available clock options depend on the installed application version.

## 🗑️ Uninstallation

To remove FlipClockScreensaver:

1. Open the extracted installation package.
2. Run `Install-Screensaver.ps1`.
3. Select option `2` – Uninstall Screensaver.

The installer removes its application files and registration when they still belong to FlipClockScreensaver.
